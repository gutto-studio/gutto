コーディングエージェントは、あなたの見えないターミナルの中で黙々と働いています：
一度走り出すと数分単位、途中で権限確認のために立ち止まる。そしてタスクが
終わったのか、承認待ちで止まっているのか分かるのは、たまたまターミナルに
戻った瞬間だけ。

`gutto` はその状態を、感じ取れる場所に置きます。デスクトップに住む小さな
メイドさんが、エージェントの状態をリアルタイムに演じます：作業中、待機中、
承認でブロック中、完了。エージェントが「許可/拒否」を求めたら、承認カードを
あなたのところへ持ってきます。そしてあなたが一息つきたいときは、立派な
ペットです——なでなで、つつき、おしゃべり。

## 課題

2026 年のエージェントは有能ですが、姿が見えません：

- **alt-tab の連続**——見なければ「動いている」のか「固まっている」のか
  判別できないので、結局ターミナルを人間が監視する羽目に。
- **承認は見ていないウィンドウに届く**——クリック一つで進むはずのタスクが、
  10 分間ブロックされたまま。
- **デスクトップに命がない**——マシンはすごい仕事をしているのに、その
  過程を何も見せてくれない。

gutto は「見えない」「承認で詰まる」「殺風景」の三つを一度に解決します。

## 見守りの仕組み

エージェントランタイムが hooks でライフサイクルを報告し、gutto がそれを
デスクトップで再生します。

1. エージェントがタスクを開始 → gutto が出勤し「作業中」に——机で
   タイピング、しっぽが揺れます。
2. エージェントがツール承認待ち → gutto が**ブロッキング承認カード**を
   表示：コマンドを確認して `⇧⌘Y` で許可、`⇧⌘N` で拒否。エージェントは
   あなたの判断で本当にブロックされます——ターミナルと同じ挙動です。
3. タスク完了 → 報告に来ます。長時間アイドル → 画面を散歩して、うたた寝
   （夜はもっと眠ります）。
4. いつでも話しかけられます——メモリ圧縮つきチャット、スラッシュコマンド、
   カスタムコマンド、キャラカード取り込み。API キーはご自身で。

対応ランタイム（2026 年現在）：**Claude Code、ZCode、Codex**（hooks による
本物のブロッキング承認）と **opencode**（通知のみのプラグイン）。

## gutto との一日

インストールは一度だけ（macOS）：

```bash
$ git clone https://github.com/gutto-studio/gutto
$ cd gutto && bin/gutto up        # 出勤——ログイン時自動起動はデフォルトで有効
```

あとの一日は三つのジェスチャーだけ：

- **なでる／つつく**——アニメーションとセリフで応えてくれます。4 回連続で
   つつくと毛を逆立てます。
- **右クリック**——チャット、設定、記録、そして「画面をのぞく」メニュー。
- **放置する**——画面を散歩し、時計を見て、夜になったら自分で布団へ。

彼女が気づいたことは積み重なります：好感度システムがなでる・つつく・
おしゃべり・毎日の訪問を記録し（1 日の上限つき、減ることはありません）、
4 段階でレベルアップし、ときどきレアなミニシーンをアンロック。一緒に過ごした
日数も覚えています。

## 同梱物

| パート           | 役割                                                                                       |
| ---------------- | ------------------------------------------------------------------------------------------ |
| `shell-electron/`| 彼女自身：アニメーション、インタラクション、チャット UI、設定、通知（Electron 単一コードベース） |
| `integrations/`  | エージェントランタイムとの橋渡し（hooks + opencode プラグイン）→ gutto のイベントバスへ        |
| `bin/gutto`      | 出勤/退勤・状態・自動起動・チャットウィンドウ・設定を一条のコマンドで                         |
| `skills/`        | SKILL.md——あなたのエージェントに gutto のことも教えます                                      |
| `assets/`        | スプライトアトラスとアート素材（AI 生成——開示済み、ライセンス参照）                           |

## プライバシー

**テレメトリゼロ、クラウド同期ゼロ。** gutto が知るすべて——チャット履歴、
好感度、エージェントイベント——はあなたのマシンの `~/.gutto/` に留まります。
チャットはあなた自身の API キーで選択したプロバイダに接続し、gutto 自身は
バックエンドを持ちません。詳細は [docs/PRIVACY.md](docs/PRIVACY.md)。

## 不要なとき

- ローカルでコーディングエージェントを動かさない——かわいいペットでは
  ありますが、見守りが本丸です。
- 今日すぐクロスプラットフォームが欲しい——macOS でビルド・実測済み；
  コードベースは Windows/Linux も視野に入れていますが、まだ早期です。

## ステータス

アーリーステージ、活発に開発中。コアのループ——agent hooks →
デスクトップ演出 → ブロッキング承認 → チャット → 好感度——は macOS で
日々の実用に耐える安定版です。
