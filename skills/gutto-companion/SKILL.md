# gutto 桌宠陪伴

用户桌面上的宠物 gutto 实时反映 agent 的工作状态。通过一条稳定 CLI 上报（路径固定不变，桌宠不在场时命令静默成功，无需检查输出）：

```
GUTTO=~/work/gutto/pet-trial/bin/gutto
```

## 何时调用（一轮工作最多各一次，禁止逐步骤刷屏）

| 节点 | 命令 |
| --- | --- |
| 接到明确任务、开始动手 | `$GUTTO report running "开始：<任务名>"` |
| 任务成功完成 | `$GUTTO report done "<一句话结果>" "<关键数字或产出>"` |
| 失败或受阻 | `$GUTTO report failed "<卡在哪>" "<已试过什么>"` |
| 长任务等待审批/依赖 | `$GUTTO report waiting "<在等什么>"` |

## 纪律

- **一轮工作只报一次 done**：一个任务、一次修复算一轮；步骤级进度不报
- **纯聊天、纯阅读、纯检索不报**——只有「动过工」才报
- 正文一句话以内，报关键数字（测试几绿、改了几个文件）比形容词有价值
- 失败时先报坏消息再继续尝试，不瞒报
