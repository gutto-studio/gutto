코딩 에이전트는 여러분이 볼 수 없는 터미널 안에서 묵묵히 일합니다: 한 번
실행되면 몇 분씩 돌아가고, 도중에 권한 승인 때문에 멈춥니다. 그리고 작업이
끝난 건지, 승인을 기다리다 멈춰 있는 건지 알 수 있는 때는 우연히 터미널로
돌아온 순간뿐이죠.

`gutto`는 그 상태를 느낄 수 있는 곳에 옮겨 놓습니다. 데스크톱에 사는 작은
메이드가 에이전트의 상태를 실시간으로 연기해 줍니다: 작업 중, 대기 중,
승인 대기, 완료. 에이전트가 "허용/거부"를 필요로 하면 승인 카드를
여러분 앞으로 가져다줍니다. 그리고 여러분이 잠깐 쉬고 싶을 때는 훌륭한
펫이 되어 줍니다 — 쓰다듬기, 콕 찌르기, 잡담까지.

## 문제

2026년의 에이전트는 유능하지만 보이지 않습니다:

- **끝없는 alt-tab** — 보지 않고는 "돌아가는 중"인지 "멈춘" 건지 알 수
  없어서, 결국 사람이 터미널을 지켜야 합니다.
- **승인은 보고 있지 않은 창에 도착** — 클릭 한 번이면 진행될 작업이
  10분씩 막혀 있습니다.
- **데스크톱에 생기가 없음** — 기계는 놀라운 일을 하면서 그 과정을
  아무것도 보여주지 않습니다.

gutto는 "안 보임", "승인 병목", "심심함" 이 세 가지를 한 번에 해결합니다.

## 지키는 방식

에이전트 런타임이 hooks로 생명주기를 보고하면, gutto가 그것을 데스크톱에서
재현합니다.

1. 에이전트가 작업 시작 → gutto가 출근해 "작업 중" 상태로 — 책상에서
   타이핑하고, 꼬리를 흔듭니다.
2. 에이전트가 도구 승인 대기 → gutto가 **블로킹 승인 카드**를 띄웁니다:
   명령을 확인하고 `⇧⌘Y`로 허용, `⇧⌘N`으로 거부하세요. 에이전트는 여러분의
   결정에 실제로 막힙니다 — 터미널에서와 똑같이.
3. 작업 완료 → 보고하러 옵니다. 오래 가만히 있으면 → 화면을 산책하고 낮잠을
   잡니다(밤에는 더 자주 자요).
4. 언제든 말을 걸 수 있습니다 — 메모리 압축이 있는 채팅, 슬래시 명령,
   커스텀 명령, 캐릭터 카드 가져오기. API 키는 직접 준비하세요.

현재 지원 런타임: **Claude Code, ZCode, Codex**(hooks 기반 실제 블로킹
승인) 및 **opencode**(알림 전용 플러그인).

## gutto와 하루

한 번만 설치하면 됩니다 (macOS):

```bash
$ git clone https://github.com/gutto-studio/gutto
$ cd gutto && bin/gutto up        # 출근 — 로그인 시 자동 시작이 기본값
```

그 후 하루는 세 가지 동작뿐입니다:

- **쓰다듬거나 콕 찌르기** — 애니메이션과 대사로 반응합니다. 네 번 연속으로
  찌르면 털이 곤두섭니다.
- **우클릭** — 대화, 설정, 기록, 그리고 "화면 보기" 메뉴.
- **내버려 두기** — 화면을 산책하고, 시계를 보고, 늦으면 스스로 이불 속으로.

그녀가 알아차린 것은 모두 쌓입니다: 호감도 시스템이 쓰다듬기, 콕 찌르기,
대화, 매일 방문을 기록하고(하루 상한 있음, 줄지는 않음), 4단계로 레벨업하며,
가끔 희귀한 작은 장면을 잠금 해제합니다. 함께한 날짜 수도 기억합니다.

## 들어있는 것

| 구성 요소        | 역할                                                                                     |
| ---------------- | ---------------------------------------------------------------------------------------- |
| `shell-electron/`| 그녀 본인: 애니메이션, 인터랙션, 채팅 UI, 설정, 알림 (Electron 단일 코드베이스)              |
| `integrations/`  | 에이전트 런타임 다리(hooks + opencode 플러그인) → gutto 이벤트 버스                          |
| `bin/gutto`      | 출퇴근/상태/자동 시작/채팅 창/설정을 한 명령으로                                             |
| `skills/`        | SKILL.md — 여러분의 에이전트에게도 gutto를 가르칩니다                                       |
| `assets/`        | 스프라이트 아틀라스와 아트 소재 (AI 생성 — 공개 표기, 라이선스 참조)                         |

## 프라이버시

**텔레메트리 제로, 클라우드 동기화 제로.** gutto가 아는 모든 것 — 채팅
기록, 호감도, 에이전트 이벤트 — 는 여러분 컴퓨터의 `~/.gutto/`에만 머뭅니다.
채팅은 여러분의 API 키로 선택한 공급자에 직접 연결되며, gutto 자체는
백엔드를 두지 않습니다. 자세히: [docs/PRIVACY.md](docs/PRIVACY.md).

## 필요 없을 때

- 로컬에서 코딩 에이전트를 돌리지 않는 경우 — 여전히 귀여운 펫이지만,
  지켜보기가 핵심입니다.
- 오늘 당장 크로스 플랫폼이 필요한 경우 — macOS에서 빌드·실측 완료;
  코드베이스는 Windows/Linux도 겨냥하지만 아직 초기입니다.

## 상태

초기 단계, 활발히 개발 중. 핵심 루프 — agent hooks → 데스크톱 연출 →
블로킹 승인 → 채팅 → 호감도 — 는 macOS에서 일상 사용에 견딜 만큼
안정적입니다.
